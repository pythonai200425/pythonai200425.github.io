Demo 03 · Intermediate

Your First LLM Integration

Connect Ollama (local) or OpenAI directly inside n8n. Send a prompt, get an AI response, chain it to the next node. This is where your ML knowledge meets automation.

🎯 Goal

Build a workflow that sends a user-defined prompt to an LLM and returns the AI's response as a clean output field. We'll show both Ollama (local, free) and OpenAI (API key) options.

🤖 Supported LLM Options

Model / Providern8n NodeKey needed?Notes
Ollama (llama3, mistral…) Ollama Chat Model Local Free, runs on your machine. Must have Ollama running.
OpenAI GPT-4o / 4o-mini OpenAI Chat Model API Key Fast, smart. Costs money per token.
Anthropic Claude Anthropic Chat Model API Key Great reasoning. Also paid.
Google Gemini Google Gemini Free tier Free tier available via Google AI Studio.
💡 Recommended for class: Use Ollama with llama3 if you have it running locally, OR use OpenAI gpt-4o-mini with a shared class API key. Both use the same n8n nodes — just swap the credential.

📋 Step-by-Step Instructions

1

Create workflow + Manual Trigger

New workflow named "03 - LLM Chat". Add Manual Trigger as before.

➕ Add workflow → "03 - LLM Chat" Add Manual Trigger node
2

Add "Edit Fields" to set the prompt

Add an Edit Fields node. We'll store the prompt as a field so we can reference it later (or change it easily).

Edit Fields — Set prompt field
Name
prompt
Value
Explain what a neural network is in 2 sentences, like I'm a Python developer.
3

Add the "Basic LLM Chain" node

This is n8n's high-level AI node. Hover the Edit Fields node → click its + connector.

🔍 Search: "Basic LLM Chain" Click: Basic LLM Chain

The Basic LLM Chain node has a special sub-connection slot at the bottom — that's where you plug in the actual AI model.

Basic LLM Chain — Settings
Prompt
={{ $json.prompt }}
Set Prompt to: ={{ $json.prompt }}
4

Connect the Chat Model (choose one)

The Basic LLM Chain needs a "brain". On the bottom of the Basic LLM Chain node you'll see a 🤖 Chat Model input connector. Click it.

For Ollama you need it running locally on port 11434 (default Docker setup).
🔍 Search: "Ollama Chat Model" Click: Ollama Chat Model
Ollama Chat Model — Settings
Base URL
http://host.docker.internal:11434
Model
llama3 (or mistral, gemma2, etc.)
⚠️ Use host.docker.internal (not localhost) because n8n runs inside Docker!
Needs an OpenAI API key. Set it once in n8n credentials.
🔍 Search: "OpenAI Chat Model" Click: OpenAI Chat Model
OpenAI Chat Model — Settings
Credential
Click "Create new credential" → paste API key
Model
gpt-4o-mini (fast & cheap)
5

Add a System Message (optional but recommended)

In the Basic LLM Chain settings, scroll down to find "Messages" section. Add a system message:

Messages → Add System Message
Role
system
Content
You are a helpful AI tutor for Python developers learning ML. Keep answers concise and practical.
6

Run and inspect the output

Click Test workflow. The LLM Chain node will light up purple while thinking, then green when done.

▶ Test workflow Click LLM Chain node → Output
✓ LLM Chain Output
{
  "text": "A neural network is a computational model loosely inspired by the brain,
consisting of interconnected layers of nodes (neurons) that learn patterns
from data by adjusting their connection weights during training.
In Python, libraries like PyTorch and TensorFlow let you define and train
these networks with just a few lines of code."
}
7

🏆 Challenge: Dynamic prompts

Change the Edit Fields prompt to something related to your ML work. Try:

"Explain overfitting in 1 sentence." "What's the difference between BERT and GPT?" "Write a Python function to normalize a list of numbers."
