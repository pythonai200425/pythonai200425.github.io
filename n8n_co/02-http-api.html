Demo 02 · Beginner–Intermediate

Call Any HTTP API

Fetch real data from the internet inside a workflow. Parse JSON, extract fields, and pass it downstream — just like requests.get() but visual.

🎯 Goal

Build a 3-node workflow that fetches a random cat fact from a public API, extracts the text, and outputs a clean result object.

🌐 Public APIs We'll Use (no key needed)

URLReturnsTry it
https://catfact.ninja/fact Random cat fact as JSON {fact, length} open →
https://official-joke-api.appspot.com/random_joke Random joke {setup, punchline} open →
https://dog.ceo/api/breeds/image/random Random dog image URL open →
https://api.coindesk.com/v1/bpi/currentprice.json Live Bitcoin price in USD open →

📋 Step-by-Step Instructions

1

Create a new workflow

In n8n at localhost:5678 click + Add workflow and give it the name "02 - HTTP API".

➕ Add workflow Name it: "02 - HTTP API" Press Enter or click Save
2

Add Manual Trigger

Same as Demo 01 — click the ➕ on the canvas and add a Manual Trigger.

🔍 Search: "Manual" Click: Manual Trigger
3

Add the HTTP Request node

Hover the Manual Trigger node → click its right-side + connector. Search for HTTP Request.

🔍 Search: "HTTP Request" Click: HTTP Request

Now configure it in the right panel:

HTTP Request — Settings
Method
GET
URL
https://catfact.ninja/fact
Method: GET URL: https://catfact.ninja/fact

Leave everything else at defaults. n8n automatically parses JSON responses.

4

Test the HTTP Request node first

Before wiring more nodes, test this one alone. Click the HTTP Request node → in the panel click "Test step".

▶ Click "Test step"

You should see output like this in the Output panel:

✓ Output (1 item)
{
  "fact": "Cats sleep 70% of their lives.",
  "length": 31
}

See that? n8n already parsed the JSON for you. No json.loads() needed!

5

Add Edit Fields to clean the output

Hover the HTTP Request node → click the right + → add Edit Fields (Set).

In the Edit Fields panel, click + Add field and set:

Edit Fields — Map fields from API response
Name
cat_fact
Value
{{ $json.fact }}
Name
char_count
Value
{{ $json.length }}
💡 n8n Expressions: Use {{ $json.fieldName }} to reference data from the previous node — like Python's data["fieldName"].
6

Run the full workflow

Click "Test workflow" at the bottom toolbar. All 3 nodes should light up green.

▶ Test workflow Click Edit Fields node → see Output
✓ Final Output
{
  "cat_fact": "Cats sleep 70% of their lives.",
  "char_count": 31
}
7

🏆 Challenge: Try a different API

Replace the URL in the HTTP Request node with the Joke API and extract setup and punchline:

URL: https://official-joke-api.appspot.com/random_joke

In Edit Fields, add fields: joke_setup → {{ $json.setup }} and joke_punchline → {{ $json.punchline }}
