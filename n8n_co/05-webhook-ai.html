Demo 05 · Advanced

Live Webhook + AI Chatbot

Create a real HTTP endpoint. POST any question to it and get an AI-generated answer back instantly. This is a production-ready microservice in 3 nodes.

🎯 Goal

Build a Webhook-triggered workflow that accepts a JSON {"question": "..."} payload, runs it through an LLM, and responds with {"answer": "..."}. Callable from Python, curl, Postman, or any frontend.

📊 Workflow Architecture

🪝
Trigger
Webhook
POST /ask-ai
🤖
AI
LLM Chain
answer question
📤
Response
Respond to Webhook
return JSON

Pink = Webhook trigger  |  Cyan = Response node  |  This workflow IS a REST API

📋 Step-by-Step Instructions

1

Create workflow + Webhook Trigger

New workflow "05 - Webhook AI". This time we start with a Webhook node instead of Manual Trigger.

➕ New workflow → "05 - Webhook AI" 🔍 Search: "Webhook" Click: Webhook
2

Configure the Webhook node

Click the Webhook node to open settings. Set it up as a POST endpoint:

Webhook — Settings
HTTP Method
POST
Path
ask-ai
Response Mode
Using "Respond to Webhook" node
HTTP Method: POST Path: ask-ai Response Mode: "Respond to Webhook" node

After setting the path, n8n shows you the webhook URL. Note it down:

Your webhook URL (test mode):
http://localhost:5678/webhook-test/ask-ai
Production URL (after activating):
http://localhost:5678/webhook/ask-ai
3

Add LLM Chain node

Hover Webhook → click + → add Basic LLM Chain. Connect your Chat Model sub-node.

Set the prompt to reference the incoming webhook body:

Basic LLM Chain — Prompt
Prompt
={{ $json.body.question }}
Prompt: ={{ $json.body.question }}

$json.body is the parsed JSON from the POST request body. .question is the field we'll send.

4

Add "Respond to Webhook" node

This node sends the HTTP response back to the caller. Hover LLM Chain → click +.

🔍 Search: "Respond to Webhook" Click: Respond to Webhook

Configure the response body:

Respond to Webhook — Settings
Respond With
JSON
Response Body
={{ { "answer": $json.text, "status": "ok" } }}
Respond With: JSON Body: ={{ { "answer": $json.text, "status": "ok" } }}
5

Activate test mode & get the URL

Click "Listen for test event" on the Webhook node — this puts it in listening mode so you can send a test request.

Click Webhook node → "Listen for test event"

The node now shows a "Listening..." badge. Your test URL is active.

6

Test with curl or Python

Open a new terminal or Python script and send a POST request:

Terminal — curl
curl -X POST http://localhost:5678/webhook-test/ask-ai \
     -H "Content-Type: application/json" \
     -d '{"question": "What is gradient descent in 2 sentences?"}'
🐍 Python — requests
import requests

response = requests.post(
    "http://localhost:5678/webhook-test/ask-ai",
    json={"question": "What is gradient descent in 2 sentences?"}
)

data = response.json()
print(data["answer"])
✓ Response JSON
{
  "answer": "Gradient descent is an optimization algorithm that iteratively adjusts model parameters in the direction that minimizes a loss function. It's the backbone of training neural networks — each step moves the weights slightly toward a lower loss.",
  "status": "ok"
}
7

Activate the workflow for production

Once tested, toggle the workflow Active in the top-right. This switches from the test URL to the production URL:

Toggle "Active" switch (top-right of editor)
Production URL (always on):
http://localhost:5678/webhook/ask-ai

The workflow now runs 24/7 as long as n8n Docker is running. This IS a microservice.

🐍 Python Comparison

    

      This workflow is equivalent to a Flask/FastAPI endpoint:

      @app.post("/ask-ai")

def ask(q: QuestionModel):

    return {"answer": llm.invoke(q.question)}


      Except n8n gives you logging, retry logic, execution history, error handling, and UI — for free, with zero code.
