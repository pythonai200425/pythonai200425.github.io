AI Agent with Tools

Give the LLM the ability to take actions: fetch web data, run calculations, execute Python code. Watch it reason step-by-step and pick the right tool — ReAct-style.

🎯 Goal

Build an AI Agent with 3 tools: an HTTP Request tool (web data), a Calculator tool, and a custom Python Code tool. The agent receives a complex question and autonomously chooses which tools to use and in what order.

🦾 What Makes This an "Agent"?

A regular LLM Chain just calls the model once. An Agent loops:

🤔 Think
What tool do I need?
→
⚡ Act
Call the tool
→
👁️ Observe
What did it return?
→
✅ Answer
Or loop again

This is the ReAct pattern — the same one used in LangChain agents and AutoGPT.

🧰 Tools We'll Give the Agent

🌐

HTTP Request Tool

Tool: HTTP Request

Calculator Tool

📋 Step-by-Step Instructions

1

Create workflow + Manual Trigger

New workflow "06 - AI Agent". Add Manual Trigger as usual.

➕ New workflow → "06 - AI Agent" Add Manual Trigger
2

Add "Edit Fields" — Set the task

Add an Edit Fields node. Set a task that requires multiple tools:

Name
task
Value
Fetch a random cat fact from https://catfact.ninja/fact, then count how many words are in the fact, and tell me both the fact and the word count.

This task requires the agent to: (1) call HTTP, (2) count words (code/calculator), (3) summarize.

3

Add the AI Agent node

Hover Edit Fields → click + → search for "Agent".

🔍 Search: "AI Agent" Click: AI Agent

In the Agent settings, set the prompt:

Prompt
={{ $json.task }}
System Message
You are a helpful research assistant with access to tools. Always use tools to get real data — never guess. Think step-by-step.
4

Connect the Chat Model (sub-node)

On the bottom of the AI Agent node, click the 🤖 Chat Model connector. Add your Ollama or OpenAI Chat Model.

Bottom connector → 🤖 Chat Model 🔍 Ollama Chat Model (or OpenAI)
Ollama: Base URL
Base URL
http://host.docker.internal:11434
Model
llama3 (or qwen2.5, mistral)
5

Add the HTTP Request Tool

On the bottom of the Agent node, click the 🔧 Tool connector. Add an HTTP Request Tool.

Bottom connector → 🔧 Tool 🔍 "HTTP Request" → Click it

The HTTP Request Tool is special — the agent gives it the URL dynamically. Configure it:

Name
fetch_url
Description
Fetches data from any URL and returns the JSON response. Use this to get live data from APIs.
Method
GET
URL
(leave dynamic — agent fills this)
💡 Tool descriptions matter! The agent reads the description to decide when to use each tool. Write clear descriptions.
6

Add the Calculator Tool

Still on the Agent's bottom Tool connector area — click + again to add more tools.

🔍 Search: "Calculator" Click: Calculator

The Calculator tool evaluates math expressions. No configuration needed — it works out of the box.

7

Add the Code (Python) Tool

🔍 Search: "Code Tool" Click: Code Tool

Configure it with a description and Python code for word counting:

Name
count_words
Description
Counts the number of words in a given text. Input: a string of text. Output: the word count as a number.
🐍 Code Tool — Python
# The agent sends input via the 'query' variable
text = query  # 'query' is the agent's input to this tool
words = text.split()
return [{"json": {"word_count": len(words), "text_preview": text[:80]}}]
8

Run the Agent and watch it reason

Click Test workflow. The Agent node will show its thinking process in the Output panel.

▶ Test workflow Click Agent node → Output → see reasoning
🤔 Agent ReAct Trace (what you'll see)
T
Thought: I need to fetch a cat fact from the URL, then count the words. Let me start by calling fetch_url.
A
Action: fetch_url → https://catfact.ninja/fact
O
Observation: {fact: "Cats can jump up to 6 times their length.", length: 42}
T
Thought: Got the fact. Now I'll use count_words to count the words in it.
A
Action: count_words → "Cats can jump up to 6 times their length."
O
Observation: {word_count: 9, text_preview: "Cats can jump..."}
✓
Final Answer: The cat fact is: "Cats can jump up to 6 times their length." It contains 9 words.

🐍 Python Comparison (LangChain)

from langchain.agents import create_react_agent, AgentExecutor
from langchain_community.tools import WikipediaQueryRun

tools = [WikipediaQueryRun(), calculator_tool, python_tool]
agent = create_react_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools)
result = executor.invoke({"input": task})
