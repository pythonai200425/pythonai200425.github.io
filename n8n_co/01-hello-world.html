Your First Workflow: Hello World

Learn the n8n canvas: add nodes, connect them, and execute your first automation in under 5 minutes.

🎯 Goal

Build a 2-node workflow: manually trigger it → set a "Hello World" message → see the output appear in the Output panel.

📋 Step-by-Step Instructions

1

Open n8n in your browser

n8n is running on Docker on your machine. Open a new tab and navigate to:

🌐 http://localhost:5678

Log in with the credentials set during Docker setup (default: admin / admin, or whatever you configured).

2

Create a new workflow

From the n8n home screen (Workflows list), click the button to create a blank canvas.

➕ Click "Add workflow" (top-right of the Workflows page)

You'll land on a blank dark canvas — this is where you build your flows.

3

Add the Manual Trigger node

Every workflow needs a trigger — something that starts it. For testing, use Manual Trigger.

Click the big ➕ in the centre of the canvas

A node panel slides in from the right. In the search box type:

🔍 Type: "Manual" Click: "Manual Trigger"

The Manual Trigger node appears on the canvas. It has a single output connector on the right side.

4

Add the "Edit Fields" (Set) node

This node lets you create or modify data fields. We'll use it to set our Hello World message.

Hover the Manual Trigger → click the ➕ on its right edge

In the node search panel that opens, type:

🔍 Type: "Edit Fields" Click: "Edit Fields (Set)"

The Set node is added and automatically wired to the trigger.

5

Configure the Edit Fields node

Click the Edit Fields node to open its settings panel on the right. Then add a field:

Edit Fields — Settings Panel
Mode
Manual Mapping
Click + Add field then fill in:
Name
"message"
Value
"Hello World from n8n! 🚀"
➕ Add field Name: message Value: Hello World from n8n! 🚀
6

Execute the workflow

Now run it! Click the big orange button at the bottom of the editor:

▶ Click "Test workflow" (bottom toolbar)

You'll see a green checkmark ✓ on each node. Click the Edit Fields node to see the Output:

Output panel → Table view:
message
"Hello World from n8n! 🚀"

🎉 Congrats! You just ran your first n8n workflow.

📥 Import This Workflow (shortcut)

hello-world.json 
{
  "name": "01 - Hello World",
  "nodes": [
    {
      "parameters": {},
      "id": "a1b2c3d4-0001-0001-0001-000000000001",
      "name": "When clicking Test workflow",
      "type": "n8n-nodes-base.manualTrigger",
      "typeVersion": 1,
      "position": [240, 300]
    },
    {
      "parameters": {
        "assignments": {
          "assignments": [
            {
              "id": "assign-001",
              "name": "message",
              "value": "Hello World from n8n! 🚀",
              "type": "string"
            },
            {
              "id": "assign-002",
              "name": "author",
              "value": "AI Class 2026",
              "type": "string"
            },
            {
              "id": "assign-003",
              "name": "timestamp",
              "value": "={{ new Date().toISOString() }}",
              "type": "string"
            }
          ]
        },
        "options": {}
      },
      "id": "a1b2c3d4-0001-0001-0001-000000000002",
      "name": "Edit Fields",
      "type": "n8n-nodes-base.set",
      "typeVersion": 3.4,
      "position": [460, 300]
    }
  ],
  "connections": {
    "When clicking Test workflow": {
      "main": [
        [{ "node": "Edit Fields", "type": "main", "index": 0 }]
      ]
    }
  },
  "active": false,
  "settings": { "executionOrder": "v1" }
}
How to import in n8n:
  1. Copy the JSON above (click Copy JSON button)
  2. In n8n, press Ctrl+A to open the command palette — OR click the 3-dot menu (⋯) in the top-right of the canvas
  3. Choose "Import from JSON"
  4. Paste the JSON and click Import
  5. The workflow loads instantly — hit Test workflow to run it

✅ What You Just Learned

🖼️

The Canvas

The dark board where you drag, drop, and connect nodes.

▶️

Trigger Nodes

Every workflow starts with one. Manual, Webhook, Cron, etc.

✏️

Set / Edit Fields

Creates or overrides data fields — like a dict assignment in Python.

📦

Items & JSON

Data in n8n flows as an array of JSON items between nodes.

🐍 Python Comparison

This workflow is equivalent to:
data = {"message": "Hello World from n8n! 🚀", "author": "AI Class 2026"}
Except n8n passes data automatically to every node downstream — no passing variables manually.
