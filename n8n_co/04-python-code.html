Write Real Python Inside n8n

Drop a Code node anywhere in your flow and write Python just like you always do. Process data, run ML logic, call libraries — then pipe results into an LLM.

🎯 Goal

Build a workflow that: (1) runs Python code to generate a fake ML model score report, (2) sends that report to an LLM for analysis, (3) outputs the AI's interpretation. Your Python skills work inside n8n unchanged.

🐍 What the Code Node Can Do

📦 Built-in modules

Use math, json, datetime, re, hashlib and more — no install needed.

📋 Access input data

All items from the previous node are in items. Each item has a .json dict.

↩️ Return new items

Your code must return a list: [{"json": {...}}, ...]. That becomes the output.

⚠️ No pip install

You can't install packages at runtime. numpy/pandas require custom Docker image setup.

Write the Python code

Delete the default code and paste this ML score report generator:

🐍 Python — Code Node 
import math
import random
from datetime import datetime

# Simulate ML model evaluation results
random.seed(42)

models = [
  {"name": "LogisticRegression", "accuracy": 0.842, "f1": 0.819, "auc": 0.891},
  {"name": "RandomForest",      "accuracy": 0.913, "f1": 0.907, "auc": 0.954},
  {"name": "SVM",               "accuracy": 0.876, "f1": 0.861, "auc": 0.922},
  {"name": "NeuralNet",         "accuracy": 0.941, "f1": 0.938, "auc": 0.971},
]

# Find best model
best = max(models, key=lambda m: m["auc"])

# Build summary string for LLM
summary_lines = ["Model Evaluation Report", "=" * 30]
for m in models:
  flag = " ← BEST" if m["name"] == best["name"] else ""
  summary_lines.append(
    f"{m['name']:20s} Acc={m['accuracy']:.3f}  F1={m['f1']:.3f}  AUC={m['auc']:.3f}{flag}"
  )

report_text = "\n".join(summary_lines)

# Return as n8n item list
return [{
  "json": {
    "report": report_text,
    "best_model": best["name"],
    "best_auc": best["auc"],
    "model_count": len(models),
    "generated_at": datetime.now().isoformat()
  }
}]
💡 Key rule: Always return a list of dicts with "json" keys. This is n8n's item format — like a list of rows in pandas.
