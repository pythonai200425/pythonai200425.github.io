Demo 04 · Intermediate

🪝 Webhook Chatbot API

Build a real HTTP endpoint inside N8N. POST a message from Python, N8N runs it through an LLM, and sends back the AI response. You'll test it live with Python's requests library.

🪝TriggerWebhookPOST /chat
→
🔗AIBasic LLM Chain
🤖ModelChat Model
→
📤ActionRespond to Webhook
Step by step
1

Add a Webhook Trigger node

New workflow → click + Add first step → search Webhook → click it.

In the right panel configure:

HTTP Method: POST
Path: chat

N8N generates a URL. You'll see two versions — use the Test URL while building:

http://localhost:5678/webhook-test/chat
Test URL only works while the workflow is open in your browser (test mode). The Production URL (/webhook/chat) works when you activate the workflow with the toggle.
2

Add a Basic LLM Chain node

Click + from Webhook → search Basic LLM Chain → click it.

Set Prompt to:

{{ $json.body.message }}

This reads the message field from the POST body that Python will send.

$json.body is the parsed POST body. $json.headers has the request headers. $json.query has URL query params. These are N8N's three request parts.
3

Attach a Chat Model sub-node

Click the + Model attachment on the LLM Chain → add OpenAI Chat Model (or Ollama).

Configure your credentials and model (same as Demo 03).

Optional — add a system prompt in the LLM Chain settings:

You are a helpful AI assistant. Answer concisely in 2-3 sentences.

4

Add a "Respond to Webhook" node

Click + from LLM Chain → search Respond to Webhook → click it.

In the panel, set Respond With to JSON.

Set Response Body to:

{{ {"reply": $json.response} }}

Respond to Webhook is what actually sends the HTTP response back to the caller. Without it, your Python requests.post() would hang waiting. N8N holds the HTTP connection open until this node fires.
5

Listen for a test request

Click ▶ Test workflow — N8N now listens on the test URL.

The workflow shows "Waiting for trigger event..." — it's ready to receive your POST request.

6

Test it from Python

Open a new terminal (keep N8N browser tab open) and run this Python code:

import requests url = "http://localhost:5678/webhook-test/chat" data = {"message": "What is the difference between supervised and unsupervised learning?"} response = requests.post(url, json=data) print(response.status_code) print(response.json())

Switch back to N8N — you should see the workflow executed and each node shows green ✅.

# Python terminal output: 200 {'reply': 'Supervised learning uses labeled training data where the model learns a mapping from inputs to known outputs, like classifying emails as spam. Unsupervised learning finds patterns in unlabeled data without known correct answers, such as clustering customers by purchase behavior.'}
✅ You built an AI chatbot API! Python sends a POST, N8N processes it with an LLM, and returns the answer. This is a production-grade pattern for AI microservices.
7

Go live — activate the workflow

Toggle the Active switch in the top right of the workflow editor.

Now use the Production URL instead:

http://localhost:5678/webhook/chat
# Same code, different URL: url = "http://localhost:5678/webhook/chat" # Send multiple questions in a loop questions = [ "What is gradient descent?", "Explain attention mechanism in transformers.", "What is overfitting and how to prevent it?", ] for q in questions: r = requests.post(url, json={"message": q}) print(f"\nQ: {q}") print(f"A: {r.json()['reply']}")
