Docker Setup

docker-compose.yml

n8n runs entirely inside Docker — no local install needed. Save the file below as docker-compose.yml, then start it with one command. Everything — workflows, credentials, settings — is stored in a named volume so nothing is lost on restart.

📄 docker-compose.yml YAML 
services:
  n8n:
    image: n8nio/n8n:latest
    ports:
      - "5678:5678"
    volumes:
      - n8n_data:/home/node/.n8n
    restart: unless-stopped
    environment:
      - N8N_HOST=localhost
      - N8N_PORT=5678
      - N8N_PROTOCOL=http
      - WEBHOOK_URL=http://localhost:5678/
      # - WEBHOOK_URL=https://your-ngrok-url.ngrok-free.dev

volumes:
  n8n_data:
$ run docker compose up -d
🐳
image: n8nio/n8n:latest
Pulls the official n8n image from Docker Hub — always the newest stable release. No manual versioning needed.
🔌
ports: 5678:5678
Maps the container's port 5678 to your host. Open localhost:5678 in any browser once it's running.
💾
volumes: n8n_data
All workflows, credentials and settings live in a named Docker volume — survives container restarts and image upgrades.
🔄
restart: unless-stopped
n8n auto-restarts after a machine reboot or Docker daemon restart. It's always available when you need it.
🌐
WEBHOOK_URL
Tells n8n what base URL to use when building webhook links. For local testing use localhost:5678.
📡
ngrok (optional)
Uncomment the ngrok line to expose your local n8n to real external webhooks from GitHub, Slack, or any service.
