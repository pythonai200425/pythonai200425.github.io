Demo 03 · Intermediate

🧠 LLM Integration

Connect N8N to a language model — OpenAI or a local Ollama instance. You already know how to call these APIs in Python. Here you wire them visually in 3 nodes.

⚡TriggerManual Trigger
→
✏️ActionSetprompt text
→
🔗AIBasic LLM Chain
🤖ModelChat Model(sub-node)
→
💬OutputAI Response

The Chat Model (OpenAI or Ollama) attaches below the LLM Chain — it's a sub-node, not a separate connection.

Step by step
1

New workflow + Manual Trigger + Set node

Create a new workflow. Add Manual Trigger, then add a Set node.

In Set, add a field: Name prompt → Value Explain what a neural network is in 2 sentences, for a Python developer.

2

Add a Basic LLM Chain node

Click + from Set → search Basic LLM Chain → click it.

In the right panel, set Prompt to:

{{ $json.prompt }}

This uses N8N's expression syntax — {{ }} reads data from the previous node's JSON. It's like Python's f-strings.

Basic LLM Chain is a wrapper for any chat model. It needs a Chat Model sub-node attached to it to know which AI service to call.
3

Attach a Chat Model sub-node

Look at the bottom of the Basic LLM Chain node on the canvas. You'll see a small + Model attachment point.

Click it → choose your model provider:

OpenAI
Ollama (Local)

Search for OpenAI Chat Model → click it.

In the panel click + Create new credential → paste your OPENAI_API_KEY.

Set Model to gpt-4o-mini (cheap, fast, capable).

You already know this API from Python — N8N uses the same endpoint. The key you paste here is stored encrypted in N8N's database.

Search for Ollama Chat Model → click it.

Set Base URL to http://host.docker.internal:11434

Set Model to llama3.2 (or whatever you have pulled in Ollama).

host.docker.internal is how Docker containers reach services running on your host machine (your laptop). If Ollama is running on port 11434 on your Mac/Windows, this URL reaches it from inside the N8N container.
# To pull a model in Ollama (run in your terminal, NOT in Docker): ollama pull llama3.2
4

Execute and see the AI response

Click ▶ Test workflow. The LLM Chain runs, calls the model, and returns the completion.

Click Basic LLM Chain → Output:

{ "response": "A neural network is a computational model inspired by the human brain, consisting of layers of interconnected nodes (neurons) that process and transform input data. In Python, you typically use libraries like PyTorch or TensorFlow to define these layers and train the network on data to learn patterns." }
✅ Your workflow called an LLM and got a completion — the same thing you do with openai.chat.completions.create() in Python, but wired visually.
5

Add a System Prompt

In the Basic LLM Chain right panel, find System Prompt Message → click Add Option.

Enter a system prompt:

You are a senior Python developer who explains ML concepts clearly and practically. Always relate concepts to Python libraries like NumPy, PyTorch, or scikit-learn.

Re-run — notice the response changes tone and references Python libraries.

This is identical to the system message in {"messages": [{"role": "system", "content": "..."}]} from the OpenAI Python SDK. N8N handles the message array construction for you.
6

Try different prompts without changing code

In the Set node change the value of prompt to anything:

→ What is the difference between LSTM and Transformer architectures?

→ Write a Python function that tokenizes a sentence into words.

→ Explain overfitting in 1 sentence, then give 3 ways to prevent it.

Execute each time and see the response change. This is the power of dynamic prompting with {{ }} expressions.
