🤖 AI Agent + Tools

Build a full autonomous AI agent — it decides which tools to use based on the question, maintains conversation memory, and you talk to it through N8N's built-in chat interface. This is the same architecture as ChatGPT plugins or LangChain agents, built visually.

The AI Agent node is the brain. Everything below it (Model, Memory, Tools) are sub-nodes that give it capabilities. The agent decides when and how to use each tool.

Step by step
1

Add a Chat Trigger node

New workflow → + Add first step → search Chat Trigger (full name: "When chat message received") → click it.

This is different from a Webhook trigger — it exposes a built-in chat UI at a special N8N URL, so you can test your agent without writing any Python.

Chat Trigger automatically handles the conversation format. It passes each message to the next node and appends the response to the conversation history when Memory is attached.
2

Add an AI Agent node

Click + from Chat Trigger → search AI Agent → click it.

In the right panel, set the System Message:

You are an expert AI research assistant for a Python and ML class. You have access to tools to fetch live data from APIs. When asked about current data, use your HTTP tool. When asked to calculate or transform data, use your Code tool. Always explain your reasoning before giving the final answer. Keep responses clear and educational.
The AI Agent node is an autonomous loop — the LLM decides what action to take, calls a tool, observes the result, and decides whether to call another tool or give the final answer. You don't hardcode the logic.
3

Attach a Chat Model sub-node

Click the + Model attachment below the AI Agent → add OpenAI Chat Model.

Set model to gpt-4o — the agent needs a strong model to reason about tool use. GPT-4o works best.

For Ollama users: use llama3.1 or qwen2.5 — these models support tool calling. Not all Ollama models do. Check with ollama list.
4

Attach a Memory sub-node

Click the + Memory attachment on the AI Agent → search Simple Memory (also called "Window Buffer Memory") → add it.

Leave defaults — it keeps the last 10 messages as context.

Without memory the agent forgets each message — every question is a fresh conversation. With memory it can answer follow-ups like "what was the second item?" or "summarize what we discussed".
5

Attach an HTTP Request Tool

Click the + Tool attachment → search HTTP Request Tool → add it.

Configure it:

Name: fetch_post_data
Description: Fetches data about a blog post by its ID (1-100). Input should be a post ID number.
Method: GET
URL: https://jsonplaceholder.typicode.com/posts/{{ $fromAI('post_id') }}

${"{"}$fromAI('post_id'){"}"} is special — it tells N8N that the AI agent decides the value of post_id at runtime. The agent reads your description, understands what input the tool needs, and fills it in. This is how agent tool use works.
6

Attach a Code Tool

Click + Tool → search Code Tool → add it.

Configure:

Name: calculate_stats
Description: Performs mathematical calculations or text analysis. Input should be a JavaScript expression or transformation to run.

In the code body:

// The agent passes its input via the 'query' variable const input = query; // Basic eval-style: return the result of a simple calculation const numbers = input.match(/\d+(\.\d+)?/g)?.map(Number) || []; const sum = numbers.reduce((a, b) => a + b, 0); const avg = numbers.length ? (sum / numbers.length).toFixed(2) : 0; return `Numbers found: ${"{"}numbers{"}"}, Sum: ${"{"}sum{"}"}, Average: ${"{"}avg{"}"}`;
7

Open the Chat UI and test

Click ▶ Test workflow — then click the 💬 Chat button that appears in the bottom right of the canvas (or the "Open Chat" link in the trigger panel).

A chat window opens. Try these messages:

👤
Fetch post number 5 and tell me about it.
🤖
I'll fetch post #5 for you right now.
🌐 Using tool: fetch_post_data(post_id=5)

Post #5 is by user 1 with the title "nesciunt quas odio". It discusses the difficulty of deciding when something is truly known versus guessed at — essentially touching on epistemology in a practical context. The post body contains 74 words.
↳ Called fetch_post_data → got JSON response → analyzed and summarized
👤
What was the user ID of that post? And can you calculate the average of 12, 45, 67, 23?
🤖
The user ID was 1 — I remember that from our previous exchange.

For the average: ⚙️ Using tool: calculate_stats([12, 45, 67, 23])

Numbers: 12, 45, 67, 23 → Sum: 147 → Average: 36.75
↳ Remembered context (memory) + called calculate_stats
✅ The agent used its memory (recalled userId from previous message), selected the right tool, called it with the correct input, and combined everything into a clear answer — all without you writing a single line of code.
8

Call the agent from Python

Activate the workflow (toggle top right). The Chat Trigger also exposes a webhook endpoint. Find the URL in the trigger panel under Webhook URL.

import requests # Chat session ID groups messages into one conversation CHAT_URL = "http://localhost:5678/webhook/your-agent-id/chat" SESSION_ID = "python-session-001" def ask_agent(message): response = requests.post(CHAT_URL, json={ "action": "sendMessage", "sessionId": SESSION_ID, "chatInput": message }) return response.json()["output"] # Multi-turn conversation print(ask_agent("Fetch post 3 and summarize it.")) print(ask_agent("How long was the body text of that post?")) # uses memory print(ask_agent("Calculate the average word count of posts 1, 2, and 3."))
Agent Architecture — What You Just Built
🧠

LLM Brain

GPT-4o reads your message and the available tool descriptions, then decides: answer directly, or call a tool first?

🛠️

Tools

Functions the agent can call. HTTP Request = browse web APIs. Code = run calculations. You define the name + description so the LLM knows when to use each one.

💾

Memory

Previous messages are injected into every new prompt as context. The agent "remembers" your conversation without any extra code.

🔄

ReAct Loop

Reason → Act → Observe → Repeat. The agent loops until it has enough information to give a final answer. This is the same pattern as LangChain agents or OpenAI function calling.
