Demo 01 · Beginner

👋 Hello World

Your first N8N workflow. You'll learn how the canvas works, how to add and connect nodes, and how to see execution output. Takes about 5 minutes.

Step by step
1

Open N8N in your browser

Go to http://localhost:5678 — your N8N instance running on Docker.

If you see the login screen, use the credentials you set up during installation.

2

Create a new workflow

Click + New Workflow (top right) — or from the left sidebar click Workflows then Create Workflow.

You'll land on the empty canvas. This is where you build your automation.

3

Add a Manual Trigger node

Click + Add first step in the center of the canvas (or press Tab).

In the search box type Manual Trigger → click it. It appears on the canvas.

What is a trigger? Every workflow needs a trigger — it defines WHEN the workflow runs. "Manual" means you click a button. Later you'll see Schedule, Webhook, and Chat triggers.
4

Add a Set node

Hover over the Manual Trigger node on the canvas — a + circle appears on its right edge. Click it.

Search for Set → click it. It connects automatically to the Manual Trigger.

What is Set? The Set node creates or overwrites fields in the data flowing through. Think of it like assigning a variable.
5

Configure the Set node

Click the Set node to open its settings panel on the right. You'll see a blank fields area.

Click Add field and fill in:

Name: message  →  Value: Hello, World from N8N! 🎉

Click Add field again:

Name: from  →  Value: Python AI Class

6

Execute the workflow

Click ▶ Test workflow in the top bar.

You should see a green checkmark ✅ appear on both nodes — the workflow ran successfully!

Both nodes show green. The workflow executed and data flowed through.
7

See the output

Click on the Set node. In the right panel switch to the Output tab.

You'll see your data as JSON:

[ { "message": "Hello, World from N8N! 🎉", "from": "Python AI Class" } ]
This is N8N's data model. Data flows as an array of JSON objects (called "items") between nodes. The next node receives this output as its input.
8

Save the workflow

Press Ctrl + S (or ⌘ S) — or click the save button at top right.

Give it a name like 01 - Hello World.

✅ You built your first N8N workflow! You know how to: open the canvas, add nodes, connect them, configure fields, and read output.
Key Concepts from This Demo
⚡
Nodes — every step in the workflow is a node. Triggers start it, actions process data, outputs return it.
→
Connections — drag from the right dot of one node to the left dot of another to connect them.
📦
Items — data flows as an array of JSON objects. Each object is one "item". This is N8N's data model.
▶
Test vs Active — "Test workflow" runs once manually. Activating (toggle top right) makes it run automatically from real triggers.
