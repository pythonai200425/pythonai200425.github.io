🌐 HTTP Request + Data

Fetch real JSON data from a public API, inspect it inside N8N, then use a Code node to transform it — just like you would with Python's requests and dict manipulation.

Step by step
1

New workflow + Manual Trigger

Create a new workflow (same as Demo 01). Add a Manual Trigger node.

2

Add an HTTP Request node

Click + from Manual Trigger → search HTTP Request → click it.

In the right panel configure:

Method
GET
URL
https://jsonplaceholder.typicode.com/posts/1
JSONPlaceholder is a free fake REST API — perfect for testing. It returns a sample blog post as JSON. No API key needed.
3

Execute and inspect the raw response

Click ▶ Test workflow. Click the HTTP Request node → Output tab.

You'll see the full JSON returned by the API:

// Raw API response — one item { "userId": 1, "id": 1, "title": "sunt aut facere repellat provident...", "body": "quia et suscipit\nsuscipit recusandae..." }
N8N wraps the response in its item format. Access any field downstream with {{ $json.title }} or in a Code node with items[0].json.title.
4

Add a Code node to transform the data

Click + from HTTP Request → search Code → click it.

The Code node runs JavaScript (think of it like a Python function that processes the items array).

In the code editor, replace all the default code with:

// items = array of objects from the previous node const post = items[0].json; return [{ json: { post_id: post.id, title_upper: post.title.toUpperCase(), word_count: post.body.split(' ').length, short_summary: post.body.slice(0, 80) + '...' } }];
N8N Code node: always return an array of {"{"}json: {"{"}...{"}"} objects. That's the item format. Each object becomes one item in the next node.
5

See the transformed output

Click ▶ Test workflow again. Click the Code node → Output.

{ "post_id": 1, "title_upper": "SUNT AUT FACERE REPELLAT PROVIDENT...", "word_count": 40, "short_summary":"quia et suscipit\nsuscipit recusandae..." }
✅ You fetched real API data and transformed it. This is the core pattern for any data pipeline in N8N.
6

Bonus — fetch multiple posts with IF branching

Change the URL to https://jsonplaceholder.typicode.com/posts — this returns 100 posts.

Add an IF node after HTTP Request. Configure:

Value 1: {{ $json.userId }}  ·  Operation: Equal  ·  Value 2: 1

The True branch gets user 1's posts, False branch gets everyone else's. Run it to see two output paths.

IF node = an if/else for your workflow. True items go down the green path, False items go down the red path. This is how you add conditional logic without code.
