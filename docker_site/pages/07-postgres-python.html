🐘 Chapter 07

PostgreSQL + Python

Run a real PostgreSQL 16 database inside Docker and connect to it from a Python script — no installation, no config files, just docker run.

🎯
Chapter Goal
Spin up a fully configured PostgreSQL database with a single Docker command, then write a Python script using psycopg3 that creates a table, inserts rows, and queries them back.

How It Fits Together

  Your Machine
  ┌──────────────────────────────────────────────────────┐
  │                                                       │
  │  pg_test.py             Docker Container             │
  │  ┌────────────┐         ┌──────────────────────┐    │
  │  │ psycopg    │─ :5432 ─▶  postgres:16          │   │
  │  │ (Python)   │◀─────── │  user: appuser        │   │
  │  └────────────┘         │  db:   appdb          │   │
  │                          │  pass: apppass        │   │
  │                          └──────────────────────┘   │
  │                                                       │
  └──────────────────────────────────────────────────────┘
  Python runs on YOUR host — Postgres runs in Docker.
  Port 5432 is mapped through.

1 Run the PostgreSQL Container

bash
docker run -d \
  --name pgdemo \
  -e POSTGRES_USER=appuser \
  -e POSTGRES_PASSWORD=apppass \
  -e POSTGRES_DB=appdb \
  -p 5432:5432 \
  postgres:16

Wait for PostgreSQL to be ready:

bash
docker logs -f pgdemo

Press Ctrl+C once you see: database system is ready to accept connections

Environment VariablePurpose
POSTGRES_USERCreates a superuser with this name
POSTGRES_PASSWORDPassword for the superuser (required)
POSTGRES_DBCreates a database with this name on startup

2 Write the Python Script

Create a file called pg_test.py on your host machine:

python
import psycopg

# Connect to the PostgreSQL container via localhost:5432
conn = psycopg.connect(
    "host=localhost port=5432 dbname=appdb user=appuser password=apppass"
)

with conn.cursor() as cur:
    # Create table if first run
    cur.execute("""
        CREATE TABLE IF NOT EXISTS users (
            id   SERIAL PRIMARY KEY,
            name TEXT NOT NULL
        )
    """)

    # Insert a row
    cur.execute("INSERT INTO users (name) VALUES (%s)", ("Alice",))

    # Query all rows
    cur.execute("SELECT id, name FROM users ORDER BY id")
    rows = cur.fetchall()

conn.commit()
conn.close()

print("Users in database:")
for row in rows:
    print(f"  {row[0]}: {row[1]}")
ℹ️
psycopg vs psycopg2
This uses psycopg3 (installed as the psycopg package). It's the modern, async-ready successor to psycopg2. The API is nearly identical but psycopg3 uses %s placeholders in all queries, even for non-string types.

3 Install & Run

bash
# Create a virtual environment
python -m venv .venv

# Activate it
# On Windows (PowerShell):
.venv\Scripts\Activate.ps1
# On Mac/Linux:
source .venv/bin/activate

# Install psycopg with the binary C extension
pip install "psycopg[binary]"

# Run the script
python pg_test.py

Expected output:

output
Users in database:
  1: Alice

Run python pg_test.py again — you'll see two Alice rows because the container is still running with its data intact.

Bonus: Connect with psql

You can also connect interactively using the psql tool — no local PostgreSQL installation needed!

bash
docker exec -it pgdemo psql -U appuser -d appdb
sql (psql prompt)
SELECT * FROM users;
\dt          -- list tables
\q           -- quit

Cleanup

bash
docker rm -f pgdemo
⚠️
Data is gone!
Removing the container without a volume also deletes the database. In the next chapters, you'll learn to use Docker Compose with a named volume so data persists between restarts.

Quick Exercise

  1. Add a second insert in pg_test.py for "Bob".
  2. Add a parameterized query that selects only users whose name starts with "A": WHERE name LIKE %s with ("A%",).
  3. Print the row count before and after inserting using cur.rowcount.
  4. Restart the container with docker restart pgdemo — is your data still there?
  5. Remove and recreate the container — is your data gone?
