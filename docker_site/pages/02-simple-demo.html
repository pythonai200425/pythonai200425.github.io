🐧 Chapter 02

Run Simple Containers

Run an interactive Linux shell inside Docker and spin up a live Nginx web server — and understand ports, flags, and container control.

🎯
Chapter Goal
Use -it for interactive containers and -d -p for background web servers. Control running containers with start, stop, logs, and rm.

A Interactive Ubuntu Shell

Run a full Ubuntu Linux environment that lives only while your terminal session is open:

bash
docker run -it ubuntu bash

Your prompt changes to something like root@3f9a2c1d:/# . You're inside the container! Try:

bash (inside container)
cat /etc/os-release    # confirm it's Ubuntu
ls /                   # see the container filesystem
hostname               # short container ID
exit                   # leave and stop the container
FlagFull NameWhat It Does
-i--interactiveKeep STDIN open so you can type commands
-t--ttyAttach a pseudo-terminal (gives you a prompt)
-it(combined)Use both — standard for interactive sessions
💡
Isolation in action
Install something with apt-get install -y curl inside the container, then exit and run a new Ubuntu container. It won't have curl — each container starts fresh from the image.

B Nginx Web Server (Detached)

Run Nginx as a background service and map a port so your browser can reach it:

bash
docker run -d --name mynginx -p 8080:80 nginx

Open http://localhost:8080 — you should see the Nginx welcome page. 🎉

  Your Browser           Docker Host              Container
  ┌──────────┐           ┌──────────┐             ┌────────┐
  │ :8080    │──────────▶│  -p      │────────────▶│ :80    │
  │          │           │ 8080:80  │             │ nginx  │
  └──────────┘           └──────────┘             └────────┘
   Host port                bridge                Container
   (your machine)                                  port

The -p HOST:CONTAINER flag maps a port on your machine to a port inside the container. You can change the host port freely — the container always listens on 80.

Manage the Running Container

bash
docker ps                # confirm it's running
docker logs mynginx      # see access logs
docker logs -f mynginx   # follow logs in real time (Ctrl+C to stop)
docker stop mynginx      # graceful shutdown
docker start mynginx     # start it again
docker rm -f mynginx     # force-stop and remove in one step

Run Flags Cheat Sheet

FlagExamplePurpose
-ddocker run -d nginxDetached / background mode
--name--name mynginxGive the container a friendly name
-p-p 8080:80Map host port to container port
--rmdocker run --rm ubuntuAuto-remove container on exit
-itdocker run -it ubuntu bashInteractive terminal

Quick Exercise

  1. Run the httpd (Apache) image on port 8081 with name myapache.
  2. Verify both Nginx (port 8080) and Apache (port 8081) run simultaneously — two containers, one machine.
  3. Use docker logs to see the access log of each when you visit them in a browser.
  4. Remove both containers with a single docker container prune.
