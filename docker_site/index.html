Course Curriculum

Complete chapters in order for the best experience — each one builds on the last

Chapter 01 🌍
Hello World Docker
Run your first container and understand what actually happens under the hood — images, registries, and layers explained.
docker run docker ps images
Chapter 02 🐧
Run Simple Containers
Run an interactive Linux shell and a live Nginx web server. Learn port mapping and container control commands.
-it -d -p nginx
Chapter 03 📁
Files & Volumes
Three ways to move data in and out of containers: copy, bind mounts, and named volumes for persistent storage.
docker cp -v volumes
Chapter 04 🏗️
Build Your Own Image
Write a Dockerfile, build a custom Python web server image, and understand layer caching to speed up builds.
Dockerfile docker build layers
Chapter 05 🔌
Env Variables & Networks
Pass configuration via environment variables and connect containers on user-defined networks using DNS names.
-e --network DNS
Chapter 06 🔍
Debug & Lifecycle
Master the container lifecycle — logs, exec, pause/resume — and safely clean up unused Docker resources.
docker logs docker exec prune
Chapter 07 🐘
PostgreSQL + Python
Run a real PostgreSQL database in Docker and connect to it from a Python script — no Docker Compose yet.
postgres:16 psycopg SQL
Chapter 08 🎼
Docker Compose Basics
Replace long docker run commands with a clean YAML file. Define multi-service apps and manage them with one command.
compose up services YAML
Chapter 09 🚀
Compose: Python + Postgres
Build a complete app stack — a Python service that talks to PostgreSQL — all wired together in one Compose file.
depends_on build volumes
Chapter 10 🏆
Best Practices & Next Steps
Production-ready habits: slim images, .dockerignore, multi-stage builds, health checks, and a final challenge project.
multi-stage .dockerignore HEALTHCHECK
